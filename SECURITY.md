# Security Policy

## Reporting a vulnerability

Please do not report security vulnerabilities in public issues.

Use GitHub's private vulnerability reporting feature for this repository. Include the affected version, reproduction steps, impact, and any suggested mitigation. Do not include real credentials, personal data, or production secrets in the report.

## Important usage notes

React-Lara Forge generates a starter application, not a fully security-audited production system. Review authentication storage, authorization, CORS, environment secrets, rate limits, logging, and deployment configuration before exposing a generated application publicly.
